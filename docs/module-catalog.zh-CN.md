# 模块目录

设置 → 模块里每个模块：做什么、出现在哪里、默认开不开、「精简」留不留。分组和顺序与设置页相同（shared/moduleGroups.ts），出现位置由模块登记的界面位置自动得出。回答「某个模块该不该开」时读这份。

一键设置：「精简」只留日常工作要用的；「推荐」是每个模块自己的默认；「全部」打开所有已安装的模块。三者都不动核心模块和可选模块。

## 工作

### 委托 (`delegations`)

- 做什么：智能体之间的委托，显示在状态行和胶囊里
- 出现在：侧栏入口、页面、Shelf 组件、状态行、对话时间线、项目页标签
- 默认：开
- 「精简」：留着

### 子智能体 (`subagents`)

- 做什么：正在工作的子智能体，显示在状态行和胶囊里
- 出现在：Shelf 组件、状态行、对话时间线
- 默认：开
- 「精简」：留着

### 目标 (`goal`)

- 做什么：线程目标（/goal）在状态行和胶囊里的一类：目标、用时、预算、暂停 / 继续
- 出现在：状态行
- 默认：开
- 「精简」：留着

### 计划 (`plan`)

- 做什么：模型的进度列表（update_plan）在状态行和胶囊里的一类
- 出现在：状态行
- 默认：开
- 「精简」：留着

### 后台终端 (`background-terminals`)

- 做什么：查看智能体的后台终端、CPU 和内存使用情况，并终止终端
- 出现在：状态行
- 默认：开
- 「精简」：留着

### 闹钟 (`alarms`)

- 做什么：查看和取消智能体设置的提醒
- 出现在：状态行
- 默认：开
- 「精简」：留着

### 快速启动 (`quick-chats`)

- 做什么：侧栏「快速启动」入口和草稿页
- 出现在：侧栏入口、页面
- 默认：开
- 「精简」：关掉

### 项目视图 (`project-view`)

- 做什么：查看项目内智能体的工作、委托、作业和最近动态，可从 Shelf、快速切换或项目菜单打开
- 出现在：侧栏入口、Shelf 组件、项目页标签
- 默认：开
- 「精简」：关掉

### 作业 (`jobs`)

- 做什么：主机上的后台作业，显示在状态行和胶囊里；仅 Linux 主机
- 出现在：侧栏入口、页面、状态行
- 默认：开
- 被这些模块依赖：NCI 远程作业
- 「精简」：关掉

### 工作流 (`workflows`)

- 做什么：智能体在你明确要求时写的编排脚本：批准运行计划，看每一步的进度和结果，停止或继续（需要 cutex workflows）
- 出现在：侧栏入口、页面
- 默认：关
- 「精简」：关掉

### 服务 (`services`)

- 做什么：查看和打开智能体启动的 Web 服务
- 出现在：侧栏入口、页面、项目页标签、设置里的一节
- 默认：开
- 「精简」：关掉

### 个人助理 (`personal-assistants`)

- 做什么：由你配置的个人助理：替你安排所选项目的工作，经你确认后把请求交给项目主管
- 出现在：侧栏入口、页面、Shelf 组件、项目页标签
- 默认：开
- 「精简」：关掉

### 安全检查放行 (`safety-grants`)

- 做什么：在会话中查看完全访问模式下被 Claude Code 拦截的命令，由主人批准原样重试一次
- 出现在：对话时间线
- 默认：开
- 「精简」：关掉

### Claude Science (`claude-science`)

- 做什么：在主机上并排运行多个 Claude Science 账号：每个账号一个 cutex 托管服务、自己的目录和登录，在内置浏览器里打开
- 出现在：侧栏入口、页面
- 默认：可选，随应用提供、默认关

## 浏览与资料

### 工作区 (`workspace`)

- 做什么：Shelf 里的文件、改动与文件预览，本机与远程主机一样
- 出现在：Shelf 组件、设置里的一节
- 默认：开
- 「精简」：留着

### 差异 (`diff`)

- 做什么：在 Shelf 中查看工作区的 Git 改动和单个回合的文件改动
- 出现在：Shelf 组件
- 默认：开
- 「精简」：留着

### 终端 (`terminal`)

- 做什么：在 Shelf 中打开智能体工作区的终端，由 cutex 在主机上运行
- 出现在：Shelf 组件、代码块按钮
- 默认：开
- 「精简」：留着

### 成果 (`artifacts`)

- 做什么：项目的成果库：智能体发布或自动捕获的文件的各个版本，可以预览、对比、引用
- 出现在：Shelf 组件、对话时间线、项目页标签、设置里的一节
- 默认：开
- 「精简」：留着

### 浏览器 (`browser`)

- 做什么：浏览网页和 cutex 服务；不同主机使用独立的浏览环境
- 出现在：Shelf 组件、对话时间线、托盘按钮、设置页
- 默认：开
- 被这些模块依赖：Claude Science、WhatsApp
- 「精简」：关掉

### 查找旧任务 (`session-search`)

- 做什么：在一个页面里查找旧任务：筛选、预览，再打开到那一回合
- 出现在：页面
- 默认：开
- 「精简」：关掉

### 搜索 (`thread-search`)

- 做什么：搜索当前智能体会话中你和它的消息，左键点击结果跳转
- 出现在：会话工具条
- 默认：开
- 「精简」：关掉

### 批注 (`notes`)

- 做什么：独立保存批注，在来源回合旁查阅，不进入主对话
- 出现在：Shelf 组件、会话工具条、对话时间线
- 默认：开
- 「精简」：关掉

### 书签 (`bookmarks`)

- 做什么：收藏引用，临时查看内容或聚焦已有工具；保存在桌面应用里
- 出现在：Shelf 组件、会话工具条、对话时间线、桌面小组件、托盘按钮、设置里的一节
- 默认：开
- 「精简」：关掉

### 下载 (`remote-copies`)

- 做什么：保存到这台电脑的文件：成果的版本和远程主机的文件；打开、在文件夹中显示、删除
- 出现在：Shelf 组件、设置里的一节
- 默认：开
- 「精简」：关掉

### 百度网盘 (`baidu-pan`)

- 做什么：浏览、搜索百度网盘，把文件下载到所选主机的文件夹；不能上传或删除
- 出现在：Shelf 组件
- 默认：可选，随应用提供、默认关

- 出现在：设置页

## 个人

### 桌面 (`home`)

- 做什么：在桌面查看名片、时钟、需要你、用量和固定磁贴，管理个人页；主页内容通过主机同步到其他设备
- 出现在：侧栏入口、Shelf 组件、桌面小组件、设置里的一节
- 默认：开
- 「精简」：关掉

#### 正在运行的智能体 (`running-agents`)

- 做什么：桌面上列出此刻正在工作的智能体：在做什么、已经多久，左键点击一下就打开它
- 属于：桌面（桌面小组件）
- 默认：开
- 「精简」：关掉

#### 世界时钟 (`world-clock`)

- 做什么：桌面上的几个城市的时间，像桌面时钟一样不带卡片（缺省堪培拉和重庆）；悬停可看和本地差几天、几小时
- 属于：桌面（桌面小组件）
- 默认：开
- 「精简」：关掉

### 开场 (`intro`)

- 做什么：会话从头可见时，第一个回合之上显示所用 Profile 的立绘与开场白；新建智能体和快速开始页的立绘也随它开关
- 出现在：对话时间线
- 默认：开
- 「精简」：关掉

### 桌宠 (`desk-pet`)

- 做什么：桌面上的小角色：智能体使用 token 时它会敲键盘，下方显示今天的 token 数；有事等你处理时头上显示感叹号。可拖到屏幕任意位置
- 出现在：托盘按钮、设置页、头像菜单
- 默认：可选，未下载、不开启

## 核心模块

### 项目 (`projects`)

- 做什么：项目页和侧栏入口：概览、智能体、委托、记忆、设置
- 出现在：侧栏入口、页面、对话时间线、设置里的一节
- 默认：必需，一直开着：项目设置、成员、记忆和主管轮换都从这里打开

### 审批 (`approvals`)

- 做什么：查看和处理等待主人批准的智能体操作
- 出现在：侧栏入口、页面、对话时间线、设置里的一节
- 默认：必需，一直开着：等你批准的操作都在这里处理

### 归档 (`archive`)

- 做什么：查看和恢复已归档的智能体，设置归档方式
- 出现在：设置页
- 默认：必需，一直开着：集中查看和恢复归档的智能体要靠它

### 存储 (`storage`)

- 做什么：查看主机上各类数据的大小和保留规则
- 出现在：设置页
- 默认：必需，一直开着：空间清理的确认、回执和重试要随时能看到

### 应用外壳 (`shell`)

- 做什么：管理通用、外观、通知等桌面应用设置
- 出现在：侧栏入口、页面、设置页、设置里的一节

### 对话 (`conversation`)

- 做什么：时间线与输入框
- 出现在：Shelf 组件、对话时间线、设置页
- 默认：核心，一直开着

### 连接 (`connection`)

- 做什么：管理主机连接、启动时连接和连接诊断
- 出现在：设置页
- 默认：核心，一直开着

### 智能体配置 (`agent-config`)

- 做什么：管理 Profile、新建默认值、通用指令和协作选项
- 出现在：侧栏入口、页面、设置页
- 默认：核心，一直开着

### 通知 (`notifications`)

- 做什么：设置事件的通知等级、提醒方式和桌面应用的提醒开关
- 出现在：设置页、通知方式
- 默认：核心，一直开着

### 快速切换 (`quick-switch`)

### 关于与已知问题 (`about`)
