# 桌面调试模式

设置 → 关于 → 调试模式。默认关闭，选择保存在这台设备的 `desktop-prefs.json`，不依赖主机或 daemon 版本。

- 打开后立即暂存画面、布局位移、长动画帧和 DOM 变化；原始错误包含代码、消息和来源，可一键复制。
- 首次打开后，若提示重载，可重载窗口以记录 React 提交归属。以后启动时从 preload 在 React 初始化之前安装；压缩版本的组件名可能缩短，脚本 URL 和字符位置仍可定位来源。
- 看到闪烁后，点击“保存最近 30 秒”，或在任意应用窗口按 **⌘⌥⇧F**（macOS）/ **Ctrl+Alt+Shift+F**（Windows/Linux）。原有 ⌘/Ctrl+Shift+F 面板全屏保持不变。
- 保存后会显示路径，即使设置页未打开也会出现通知；可复制路径，或在 Finder / 资源管理器 / 文件管理器中显示。
- **⌘⌥I**（macOS）/ **Ctrl+Shift+I**（Windows/Linux）打开 DevTools。录制优先使用本窗口的 Chromium 胶片流；若 DevTools 接管调试连接则回退到原生帧订阅，关闭 DevTools 后再接回胶片流。

文件夹位于 Electron 的 `app.getPath("userData")/logs/debug/<时间>/`。macOS 的默认 userData 通常在 `~/Library/Application Support/<应用名>/`；便携安装或显式 userData 配置可能不同，以应用显示的实际路径为准。录制不需要命令行、Python或对外调试端口。

片段包含：

- `index.html`：离线胶片查看页；在系统浏览器打开，可拖动时间滑块。
- `manifest.json`：应用/Chromium/Electron版本、窗口、时间戳和帧来源；JPEG 是缩小的界面画面。
- `events.json`：原始错误、React 提交、长动画帧中的脚本归属、布局/可见性/DOM变化和输入事件。它们用于关联时间，不能单凭附近一次 React 提交就认定原因。

滚动缓冲保留最近30秒，帧与事件合计最多48MiB。胶片保留 Chromium 交付的每个变化画面（只去掉连续相同的JPEG），不按时间间隔丢帧；静止、隐藏、卡住的窗口可能没有新帧，内存上限或缺少新画面也可能使片段缩短。极短闪烁可能落在两帧之间，可见性变化和脚本事件可辅助判断。原始错误和画面可能含当前工作内容；仅保存在本机，保存过的片段不会自动删除。

关闭后立即结束帧订阅/本工具拥有的调试连接、定时器和观察器，并清空内存缓冲；不会关闭别人的 DevTools或调试连接。既有错误日志仍照常工作。

CDP 胶片不提供真实绘制损伤矩形；`manifest.json` 中这类帧的零矩形表示未知，不能据此认定没有重绘。
