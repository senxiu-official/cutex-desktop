# Mobile access boundaries

The current public set does not include a mobile application. Phone pairing and mobile push notifications remain unavailable. Device-token scopes and user permissions are intersected by the host; pairing does not grant unconditional owner access. Desktop support and future mobile integration must use the same Management API permission checks. See [Known issues](../KNOWN-ISSUES.md).

See [Architecture](../DESIGN.md) and [Module contracts](../desktop-modules.md) for related interfaces.
