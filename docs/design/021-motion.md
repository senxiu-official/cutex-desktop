# 021 动效：一套规则

状态：**已实现，待合并**（10-22，feat/0.2-motion）。清单 #24（主人：照做）。

## 规则

**三档时长、一条曲线**（`motion.css` 的 CSS 变量，`lib/motion.ts` 给 JS 用同样的值，测试锁住两边一致）：

| 档 | 时长 | 用在哪 |
|---|---|---|
| 短 `--motion-short` | 120 ms | 反馈和小东西出现：悬停 / 按下的淡入淡出、Rail 名字卡片、动作预告的描边、拖放目标区、托盘图标悬停 |
| 中 `--motion-medium` | 200 ms | 面板变化：{{shelf}} 展开 / 收起、最大化 / 独占 / 全屏、整行滑动、侧栏宽度、托盘浮出 / 收回、窗口顶栏浮出、提示条出现 |
| 长 `--motion-long` | 280 ms | 东西进出屏幕：窗格打开、小片飞到托盘、焦点描边移到另一个工作区、桌面亮度渐变 |

曲线只有一条 `--ease-standard` = `cubic-bezier(0.2, 0.8, 0.2, 1)`（起步快、落地轻）。

**会动的**：{{shelf}} 展开 / 收起；工作区打开 / 关闭（会话滑到新位置）；收成窄条 / 只看 {{shelf}}（同一套滑动）；最大化 / 独占 / 全屏；
两个工作区之间的焦点描边；托盘自动隐藏时的浮出；动作预告的描边；页面 / 窗格拖放时的目标区；提示条（底部的撤销提示、智能体提示）。

**从不动的**：拖宽度边、方向键调宽度（拖动中）；窗口大小变化；第一次画出来的界面（启动后头两帧所有过渡关掉）。

**减少动态效果**（系统设置）：三档时长都变成 0，用这些变量的地方全部立刻到位；JS 的动画（{{shelf}} 盒子、整行滑动、小片飞行）不跑。

**例外**（不是两种布局之间的过渡，保留自己的节奏）：转圈 / 呼吸 / 闪烁这类循环、倒计时（二次确认 5 秒）、
「需要你」的提醒闪动、全屏提示停留 2.2 秒、覆盖滚动条自己的显隐时间、对话里内容自己的小动画（输入框滑块、进度条、关于页的小龙）。
