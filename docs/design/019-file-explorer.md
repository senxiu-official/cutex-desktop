# 019 文件浏览器（Shelf 里的「文件」窗格整体重做）

状态：**已实现**（`feat/0.2-files`，10-22；主人把 1–6 交给主管定，见文末「决定」）。来源：主人 10-22「现在的 shelf 里的文件树做得很不好——没法返回上一个之类的？打开的文件最好能让我在
文件树中显示——总之是参考一下成熟 file explorer。不要为了我的很散的需求就一次改一点」；同日补充场景「我想把项目 A 的预览和文件树并排看，
比如翻智能体生成的图片」。

原型：`.claude/preview-file-explorer.html`（单文件，离线可用，浅色 / 深色；顶上的滑块改窗格宽度。地址后面加 `#fresh` 从头开始，再加 `,gallery` 图片文件夹、`,reveal` 在文件树中显示、`,search` 全部搜索、`,filter` 筛选、`,narrow` 窄窗格、`,dark` 深色）。截图 `shots/0.2-files/`。

这是**一次成套的重做**，不是零散补丁：一个窗格 = 地址栏 + 树 + 内置预览，规则一次定下。

`fs/file`、`fs/watch`、`git/status`），远程主机和本机一样——这一点是对的，保留。缺的东西：

## 方案

### 1. 窗格的样子

```
┌ 文件 ─────────────────────────────────────────────────────────┐
│ ← → ↑ │ [▣ cutex-desktop ▾] › apps › desktop › src ›   │ ◎ ⋯ ▥ │  地址栏
│ [筛选当前文件夹…                    ] [全部搜索]                │  筛选
├───────────────────────────┬──────────────────────────────────┤
│ ▸ assets                  │  logo.png                    ↗ ⋯ │
│ ▾ renderer/src     M ●    │                                  │
│   ▸ components            │        （图片 / 代码 / Markdown） │
│   ▸ lib                   │                                  │
│     store.ts          M   │  1.2 MB · 512×512 · 10-22 14:03  │
│   logo.png      ◀ 选中    │                                  │
└───────────────────────────┴──────────────────────────────────┘
```

- **地址栏**：← 后退、→ 前进、↑ 上一级；面包屑（第一段是**根**，带 ▾ 换根）；◎ 定位当前文件；⋯ 视图选项；▥ 预览开 / 关。
- **筛选行**：输入就筛选（见 §5）；「全部搜索」= 搜整个工作区。
- **树**：从**当前位置**往下（见 §2）。
- **内置预览**：选中的文件显示在旁边；窗格宽 ≥ 560 px 时在右边，窄了在下面（高度 ≥ 420 px），再小就不显示（▥ 按钮仍可强行打开，盖在树的下半部分）。中间一条可拖的分隔线，比例按窗格记住；双击分隔线 = 缺省（各一半）。

### 2. 位置和历史（后退 / 前进 / 上一级）

- 窗格有一个**当前位置**（一个文件夹）。树的顶就是它，面包屑写的也是它。缺省 = 根。
- **进入**一个文件夹（换位置）：双击文件夹、在文件夹上按 Enter、点面包屑的一段、从段的下拉里选、从地址栏输入路径、「在文件树中显示」需要时（§3）。
- **单击**文件夹只是就地展开 / 收起（和现在一样），**不**换位置、不进历史。
- **历史** = 换位置的记录，每条记着「位置 + 选中的项 + 滚动位置」：后退回到上一个位置时，选中和滚动也回来（像浏览器）。最多 50 条；
  后退之后再进入别处，前进的记录丢掉（和浏览器一样）。后退按钮右键 / 长按 = 列出历史，点一条直接跳。
- ↑ 上一级：位置变成父文件夹，原来的文件夹被选中（Windows / Finder 都这样）。在根上时 ↑ 变灰。
- 快捷键（焦点在窗格里）：Alt+← / Alt+→ / Alt+↑；macOS 另加 ⌘[ / ⌘] / ⌘↑。鼠标侧键（后退 / 前进）也认。
- 历史只在内存里（重启后从记住的位置开始，没有历史）；**位置、展开的文件夹、选中项、视图选项**按「主机 + 根」记住（实例状态，重启还在）。

### 3. 在文件树中显示 / 跟随

- **「在文件树中显示」**（Reveal）入口：预览卡片的路径行（新 ◎ 按钮，面包屑每一段也能点）、Shelf 里预览标签的右键菜单、对话里文件链接的右键菜单、
  改动列表的行、diff 卡片的标题、⌘K 里的文件结果。快捷键 **Ctrl/⌘ Alt R**（与 VS Code「在系统中显示」不冲突，暂定）。
- 显示的规则：
  1. 这个智能体的「文件」窗格存在 → 用它（在它自己的 Shelf，017）；不存在 → 按缺省位置开一个。
  2. 文件在当前位置下面 → 不换位置；把路上的文件夹展开、选中它、滚到中间、闪一下。
  3. 不在当前位置下面 → 位置换成**它所在的文件夹**（进历史，后退就回来）。
  4. 文件被筛选藏起来了 → 清掉筛选再显示（和现在 reveal 清搜索一样）；被「隐藏文件」「隐藏被忽略的」藏起来了 → 这一次照样显示，行上标「已隐藏」。
  5. 文件在工作区外（主机绝对路径）→ 根能换到包含它的地方就换（§7）；换不了就提示「在工作区外，文件树显示不了」（现在的提示）。
  6. 窗格收着 / 是小片 → 展开 / 放回原位；焦点给树（从键盘发起的）或不动（从鼠标发起的，只闪一下）。
- **跟随当前文件**（⋯ 里的开关，缺省**开**，像 VS Code）：这个智能体最近用的预览卡片换文件时，树把它选中并展开到它——**只在它属于当前位置时**。
  不在当前位置下时**不自动换位置**（自动跳会搅乱后退 / 前进），◎ 按钮亮起提示「当前文件不在这个文件夹下 · 点一下定位」。
- 内置预览里选中的文件就是树里选中的，不另算「跟随」。

### 4. 树的行为

- **展开状态**按「主机 + 根」记住（最多 300 个文件夹，超了丢最久没碰的）；**全部收起**（⋯ 和地址栏右键；快捷键 ←← 连按在根上也行）。
- **紧凑文件夹**（缺省开，⋯ 可关）：只有一个子文件夹、没有文件的文件夹并成一行 `src/main/java`；点其中一段 = 那一段单独展开 / 进入。要知道「只有一个子文件夹」
  需要多读一层，所以展开时如果只剩一个子文件夹，就顺手把它也读了。
- **吸顶**：往下滚时，当前行所在的父文件夹们贴在树的顶上（最多 3 层），点一下滚回去。
- **排序**（⋯）：名字（缺省，自然排序：`file2` 在 `file10` 前，不分大小写）/ 修改时间 / 大小 / 类型；正序 / 倒序；「文件夹在前」（缺省开）。都在本地排（cutex 给了大小和时间）。
- **隐藏文件**（`.` 开头）：缺省**显示**（智能体常用 `.github`、`.claude`）；⋯ 可关。**被 git 忽略的**：缺省显示但变淡；⋯ 可选「不显示」。`.git` 本身 cutex 不给。
- **git 装饰**（用已有的 `git/status`）：文件名后面 M（改了，黄）、A（新增，绿）、U（未跟踪，绿）、D 不在树里（删掉的只在改动列表）、!（冲突，红）；
  名字颜色跟着变。文件夹上一个点 = 里面有改动（收起时也看得到）。⋯ 里「只看改动」= 树里只留有改动的文件和它们的文件夹。
- **键盘**（树有焦点时；一个 Tab 进树，再 Tab 出去）：
  ↑ ↓ 移动；→ 展开 / 已展开就进第一个子项；← 收起 / 已收起就回父文件夹；Home / End；PageUp / PageDown；
  **Enter** = 文件：在单独的预览窗格打开（Ctrl/⌘ Enter = 新的保留标签，和现在一样）；文件夹：进入（换位置）；
  **空格** = 内置预览开 / 关（Quick Look）；直接打字 = **按字母跳**到下一个名字以这些字母开头的可见行（0.7 s 内连续打的字母算一个词）；
  Ctrl/⌘ F 或 `/` = 去筛选框；Esc = 先清筛选，再清多选；Ctrl/⌘ C = 复制选中项的相对路径（多选时每行一个）；Ctrl/⌘ Alt C = 绝对路径；
  F2 / Delete 留给以后的改名 / 删除（cutex 还没有接口）。
- **多选**：Ctrl/⌘ 点 = 加 / 减一个；Shift 点 / Shift ↑↓ = 一段。多选能做的：复制路径、在输入框里提到、拖进输入框。预览显示最后点的那个。
- **鼠标**：单击文件 = 选中 + 内置预览（内置预览关着时 = 像现在一样开预览卡片）；双击文件 = 在单独的预览窗格打开并保留；中键 = 新的保留标签。

### 5. 筛选和搜索

- **筛选**（输入即生效，像 VS Code 树上打字）：只在**已经读过的**行里按名字找（不区分大小写，片段匹配，匹配的字高亮）；不匹配的行藏起来，匹配行的父文件夹留着。
  没有发请求，所以瞬间出来。底下一行「没找到？在整个工作区搜索 ↵」。
- **全部搜索**（按「全部搜索」或在筛选框里 Enter）：走 cutex `fs/search`（模糊，整个工作区，最多 200 条）。结果是一个平铺列表：文件名 + 灰色的文件夹路径，
  按分数排。↑↓ 移动、内置预览跟着；Enter = 打开；**Alt+Enter / 右键「在文件树中显示」** = 清掉搜索、按 §3 显示它。Esc = 回到树，树原样（展开、滚动都不变）。
- 搜索结果的文件夹路径那一段可以点 = 进入那个文件夹。
- 搜索只搜文件名（cutex 现在不支持搜文件夹和搜内容，见 API 缺口）。

### 6. 内置预览和图库

- **内置预览**用和预览卡片**同一个渲染器**（代码高亮、Markdown、SVG、图片、PDF / Office、二进制说明、截断提示）；顶上一行：文件名、↗「在单独的窗格打开」、⋯（复制路径、源码 / 渲染）。
  底下一行：大小、修改时间，图片加像素尺寸。
- 选中变化后 120 ms 才读（按着 ↓ 快速翻时不会每一行都去读）；晚到的旧结果不覆盖新的。读过的最近 20 个文件在内存里留着，来回翻不重读。
- 选中的是文件夹：预览显示「N 个文件夹、M 个文件」和前几张图的缩略图。多选：「已选 N 项」。
- **↗ 在单独的窗格打开** = 现在的预览卡片，保留标签，放在同一个 Shelf 页里（017：从窗格打开 = 进它自己的 Shelf）。
- **图库视图**（⋯ 或地址栏右边 ▦ 切换「列表 / 缩略图」）：当前位置显示成一格格缩略图，文件夹在前。
  缺省：一个文件夹里**至少 4 张图、而且图片占文件的八成以上**，第一次进去就用缩略图（像 Windows「图片」文件夹）；主人切过一次，这个文件夹就按主人的记住（按「主机 + 根 + 路径」，最多 500 个）。
  方向键在格子里上下左右走，预览跟着；Enter 在单独的窗格打开；缩略图大小 ⋯ 里三档。
- 缩略图怎么来：cutex 现在没有缩略图接口，0.2 先用 `fs/file` 读整张图（上限 2 MiB，比这大的只显示图标 + 「太大，点开看」），**只读看得见的格子**，同时最多 4 个，内存里最多留 200 张。
  远程主机上会慢一些，所以缩略图接口列为 cutex 要补的（见 API 缺口）。
- 配套：主人要「项目 A 的预览和文件树并排看」——内置预览就是这个；要整个窗口都给文件浏览器时，用 **ui-tray 在做的「收起对话但留着它的 Shelf」**（另一份方案），
  再把 Shelf 拉宽或最大化。

### 7. 根（换根）

- 面包屑第一段 = 根，▾ 列出可以换的根：**这个智能体的工作目录**（缺省，跟随选中的智能体，和现在一样）；它所属**项目的根**（和工作目录不同时）；
  0.2 之后：同一台主机上别的项目、主机上任意文件夹（需要 cutex 补接口）。
- 换根进历史（后退能回来）。每个根各记各的展开状态和位置。
- 「固定到项目 A」（不跟着选中的智能体换）需要一种新的绑定可见规则（现在 `workspace` 绑定只在选中的智能体就在那个工作区时才显示），留到 0.2 之后，见待定。

### 8. 动作（都走 cutex，远程一样）

| 动作 | 0.2 | 说明 |
|---|---|---|
| 预览（内置）/ 在单独的窗格打开 / 新的保留标签 | ✓ | 现有 `openFile` |
| 进入文件夹 / 在文件树中显示 | ✓ | 本方案 |

### 9. 大文件夹、远程、出错

- **虚拟列表**：树压平成一列行，只画看得见的（固定行高 24 px，紧凑密度 22 px），几万行也不卡。
- **一次最多画 2000 个子项**：一个文件夹超过 2000 项时先显示前 2000 项，末尾一行「还有 N 项没显示 · 用筛选或搜索找」——cutex 现在会把整个文件夹一次传回来，
  要它加上限和分页（API 缺口）。
- 文件夹按需读，读过的留着；只有展开着的文件夹跟着 `fs/watch` 刷新；收起的文件夹下次展开时重读一次（ZCode 的坑：收起的会一直旧）。
- **主机离线 / 读不到**：保留上次的内容，顶上一条「主机离线，显示的是上次读到的内容」，动作只剩复制路径。
- **正在看的文件夹被删了**：位置退到还在的最近一级父文件夹，提示一次「xxx 已不存在」；历史里指向它的记录变灰，点了同样提示。
- **选中的文件被删了**：预览显示「这个文件已被删除」，选中移到下一行。
- **权限不够**（非主人用户，`workspace_root_too_broad` / `permission_denied`）：在那个文件夹的位置写原因，不整页报错。
- **没有工作目录**：和现在一样「这个智能体没有工作目录」。
- 读得慢（> 300 ms）：那一行下面显示一条细的加载条，不闪「…」。

## 规则和边界情况

1. 树、预览、搜索的数据**只**来自 cutex（AGENTS.md 原则 2）；本地只做排序、筛选、缓存。唯一的本机动作是「在系统文件管理器中显示」，只本机主机。
2. 位置、展开、视图选项按「主机 + 根」记，不按窗格种类全局记：两个智能体共用一个工作区时共用这些记录。
3. 换选中的智能体（窗格是「跟随」）：换成那个智能体的根和它记住的位置；历史清空（历史只属于一个根）。
4. 两个工作区各有一个「文件」窗格时，各管各的（017：显示进它自己的 Shelf）。
5. 在文件树中显示的目标路径和现在 `openFolder` 的 `reveal` 参数合并成一个参数：`reveal`（文件或文件夹）+ `revealSeq`（每次显示 +1，现有做法）。旧的存档照旧能读。
6. 窗格从窄变宽（或反过来）时，内置预览在右边 / 下面之间换，选中和滚动不变。
7. 按字母跳只在树有焦点、焦点不在筛选框时生效；多语言名字按显示的字符比较（中文名也能跳到第一个字）。
8. 链接（symlink）：cutex 只在目标还在工作区内时告诉类型；指向外面的显示成带箭头的灰色项，点了提示「指向工作区外」。
9. 筛选不改变展开记录：清掉筛选后树回到原样。
10. 「跟随」只看**这个智能体**的预览卡片；别的智能体的预览不影响这棵树。
