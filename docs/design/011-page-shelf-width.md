# Shelf page width

Application pages such as projects, delegations and approvals have a default width of 640 px. Opening a page may widen its Shelf up to the available space while respecting the conversation minimum width. A Shelf already wider than the page default is not narrowed. Other workspaces keep their widths.

See [Architecture](../DESIGN.md) and [Module contracts](../desktop-modules.md) for related interfaces.
