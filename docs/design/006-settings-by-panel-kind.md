## 现在的样子（0.2 main，盘点 10-22）

- 「外观」一页装了五样东西：颜色 / 字体 / 布局 / 启动页立绘 / **窗口与卡片**（卡片材质、页面打开位置、工作区宽度、贴边显示、并排时 Shelf 的位置、
  Shelf Rail 的位置、Shelf Rail 常驻、单个对话的默认宽度、托盘常驻、托盘位置、托盘分组、桌面亮度）——画布那一轮加的面板设置几乎全在这里。
- 「右侧栏与留白」还是第 3 步右栏的说法，里面一半是 Shelf、一半是对话两边的留白；有几项（右栏布局、竖条里页按钮位置、右栏收起时、点击当前页图标）
  在 Shelf 有 Rail 以后不再起作用，「点击当前页图标」还和 10-22 的决定（点当前页不收起）冲突。
- 同一块界面的设置分在好几处：会话 = 对话 + 输入区 + 状态 + 外观里的两项 + 右侧栏与留白里的留白；桌面 = 外观（亮度、立绘）+ 桌面上的「编辑主页」。
- 面板自己的 ⋯ 里有一部分设置（Shelf ⋯ 的允许混排 / 只用一个 Shelf / Rail 内外侧，托盘右键的停靠 / 分组 / 常驻），但没有路通到设置页。

## 方案

### 1. 分类：先按面板，再按「不是面板的东西」

左栏 6 组（原型里每一项都能点）：

| 组 | 页 | 放什么 |
|---|---|---|
| **面板** | 窗口 · 侧栏 · 会话 · {{shelf}} · 托盘 · 桌面 · 设置 {{shelf}} | 屏幕上每一种面板一页（canvas §8 的面板种类）；「窗口」= 所有面板共用的（颜色、字体、缩放、密度、卡片材质、贴边、工作区宽度、动作预告、状态胶囊） |
| **智能体** | Profile · 新建默认 · 指令 · 协作 · 运行时 · 工具 | 存在主机上的 cutex 配置；原「工具」组的插件 / MCP / 技能 / 钩子并成「工具」一页四节 |
| **主机与用户** | 你 · 主机 · 用户 | 「主机列表」和「主机」合成一页（先列表，点一台进详情），主机后端更新、网络代理、NCI 远程作业做它的小节 |
| **通知与审批** | 通知与审批 | 通知方式 / 事件分级 / 提醒开关 / 主人通知；**审批**一节收「智能体申请长期服务需要审批」（原在协作）和指向 Profile 里「需我批」的链接 |
| **数据** | 用量 · 归档 | 不变 |
| **应用** | 通用 · 模块 · 键盘快捷键 · 更新与诊断 · 关于 | 语言、术语、关窗行为、启动时的视图（原在主机列表 → 启动） |

**面板页里的小节按这块面板从上到下排**（会话：会话顶栏 → 宽度 → 消息显示 → 长对话 → 输入区 → 留白 → 侧边对话）；**窗格种类的设置放在
{{shelf}} 页的小节里**（文件窗格、网页窗格、成果窗格），不另开页——窗格是 {{shelf}} 里的东西。

主要的搬家（全部见原型的「对照表」，119 行）：

| 现在 | 建议 |
|---|---|
| 外观 → 颜色 / 字体 / 布局；外观 → 窗口与卡片的卡片材质、贴边显示、工作区宽度；状态 → 胶囊 | 面板 › 窗口 |
| 左侧栏（全部）；编辑主页 →「侧栏顶部显示『桌面』」；主机列表 → 启动的两个主机标记 | 面板 › 侧栏 |
| 对话、输入区、状态 → 显示位置；外观 → 单个对话的默认宽度、对话区宽度；右侧栏与留白 → 留白 / 书签条 / 参考卡片打开位置；侧边对话、记为批注 | 面板 › 会话 |
| 外观 → 页面打开位置、并排时 Shelf 的位置、Shelf Rail 的位置 / 常驻；右侧栏与留白 → 右栏 / 打开文件 / 组件默认位置 / 成果；浏览器 | 面板 › {{shelf}}（Rail、打开在哪、宽度与布局、后台保持、文件窗格、网页窗格、成果窗格） |
| 外观 → 托盘常驻、托盘位置、分组 | 面板 › 托盘 |
| 外观 → 桌面亮度、启动页立绘；编辑主页 → 封面、一句话介绍、显示的区块、没有窗格时显示桌面 | 面板 › 桌面（编辑主页面板照旧在桌面上，内容同一份） |
| 设置导航底部的「只显示图标」、顶栏的 ⇄、宽度 | 面板 › 设置 {{shelf}} |
| 协作 → 服务（长期服务审批） | 通知与审批 › 审批 |
| 主机列表 + 主机 + 主机后端更新 + 网络代理 + NCI | 主机与用户 › 主机 |
| 插件 + MCP + 技能 + 钩子 | 智能体 › 工具 |

### 2. 入口：每种面板的 ⋯ →「…设置…」

每个面板的 ⋯（或右键）最后一行是「⚙ X 设置…」，打开设置 {{shelf}} 直接停在那一页（窗格种类的停在 {{shelf}} 页的那一节并闪一下）；面板自己
的快捷开关（允许混排、托盘分组…）照旧留在 ⋯ 里，两处改的是同一个设置。

| 面板 | 在哪 | 打开到 |
|---|---|---|
| 窗口 | 窗口顶栏「窗口布局」⊞ 菜单（和「恢复默认布局」在一起）；Ctrl+, | 窗口 |
| 侧栏 | 侧栏 ⋯ / 侧栏空白处右键（和「在主界面调整…」在一起） | 侧栏 |
| 会话 | 会话顶栏 ⋯ | 会话 |
| {{shelf}} | {{shelf}} ⋯ | {{shelf}} |
| 文件 / 网页 / 成果窗格 | 窗格头 ⋯ | {{shelf}} › 那一节 |
| 托盘 | 托盘右键 / 托盘 ⋯ | 托盘 |
| 桌面 | 桌面右键；「编辑主页」面板底部「更多桌面设置…」 | 桌面 |
| 设置 {{shelf}} | 设置顶栏 ⋯ | 设置 {{shelf}} |
| Profile | 对话底栏的 Profile 头像 ⋯ | Profile（那个 Profile 展开） |

**动作预告**（设计 008，蓝 = 在这里打开）：悬停或键盘移到「…设置…」150 ms 后——
- 设置 {{shelf}} 关着：在它会出现的地方（缺省左边、侧栏和工作区之间）描蓝框，写「在这里打开设置 ·『{{shelf}}』页；工作区让出 760 px」；
- 已经开着：描设置卡片，写「设置换到『托盘』页」；
- 同时给**这些设置管的那块面板**描一圈细实线（「这些设置管它」），打开后它闪一下——从哪来、改的是什么一眼对上。

### 3. 外观类设置不放预览图：旁边的真实界面就是预览

设置 {{shelf}} 本来就和工作区并排，所以：
- **悬停一行设置 = 在真实界面里描出它影响的面板**（虚线框 +「影响这里 · {{shelf}} Rail」），移开就消失；影响整个窗口的描整个工作行。每行下面
  还有一个小标签「影响：侧栏、托盘」，不用悬停也看得到。
- **改了立刻生效**，框跟着面板走（例如改「{{shelf}} Rail 的位置」，框跟着 Rail 换到另一边；改「托盘位置」，框跟着托盘到顶上）。
- 每行有个 ⌖「在界面里指出来」：点一下那块面板闪两下（屏幕上看不到的面板——例如收起的 {{shelf}}——写「现在不在屏幕上」）。
- 不要预览图、不要示意图；面板现在不在屏幕上时（例如没有托盘），框画在它会出现的位置并写「现在不显示」。
- 规则和动作预告同一套：同一个颜色、同一个出现时间（150 ms）、减少动态效果时没有淡入。

### 5. 不动的

- 设置的**存储和键名**都不变（搬的是页，不是数据）；搜索照旧能搜到每一项（搜索索引按新页重排）。
- 模块的 `settings.page` / `settings.section` 契约不变：模块仍按 id 挂到页上；只是页的 id 和分组变了——旧页 id（`appearance`、`sides`、`composer`、
  `status`、`hosts`…）做成别名指到新页，`services.ui.openSettings("sides")` 这类深链继续能用。真正动契约（例如给模块加「这一节属于哪种面板」）
  另开设计，先问主人和 lead。
- 存在主机上的设置照旧标「存在主机」（原型里的橙色标签），本机的不标。

## 实现时定下的细节（v1，10-22，分支 feat/0.2-settings-v1）

  - 会话：原「对话」页（对话顶部、消息显示、长对话）+ **宽度**（单个对话的默认宽度、对话区宽度，原在外观）+ **输入区**（原独立页，
    旧 id `composer` 别名到这里，卡片锚点不变）+ **留白**、书签条（原在右侧栏与留白）+ 侧边对话 + 一行「只看 {{shelf}}」说明（会话 ⋯ → 只看
    {{shelf}}：会话收成窄条，它的 {{shelf}} 变宽；没有开关）。
