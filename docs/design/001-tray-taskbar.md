# Tray navigation

The tray provides access to pinned items and recent workspaces. Opening an agent can replace the focused conversation or open it alongside the current workspace. Status marks distinguish active, running and needs-attention items. Workspace grouping and recent-item behavior are described in [Workspace groups](039-workspace-groups.md).

See [Architecture](../DESIGN.md) and [Module contracts](../desktop-modules.md) for related interfaces.
