# 001 托盘 = 任务栏

状态：**已实现**（10-22，分支 feat/0.2-tray，待合并；原定 10-21）；分组方式：缺省 **A 不分组**，B 按状态、D 按项目做成设置项（10-21 主人：听默认）。清单 #15、#36。预览：`.claude/preview-tray-taskbar.html`。

## 问题

两个会话并排时点侧栏的另一个智能体 = 替换聚焦的那一列。被换掉的会话**不留任何痕迹**：托盘只放钉住的东西，没有「返回」。主人：「不太原生」。

## 决定

照 Windows 任务栏 / macOS Dock：
- **托盘 = 钉住的 + 打开着的**。被替换的工作区不关闭，变成「打开着、不在屏幕上」，留在托盘里；点它换回来（替换聚焦的那一列），Ctrl/⌘+点 = 并排。
- **标记**：在屏幕上 = 图标下亮条；打开着 = 小点；只钉住 = 无。另有需要你（红角标）、运行中（转圈）。
- **关闭才离开**：托盘里关掉一个没钉住的打开项，它从托盘消失；钉住的一直在。
- 悬停侧栏的智能体时，将被替换的那一列描红色虚线并提示「点击会替换 X（它会留在托盘里）」。
- 托盘图标悬停同样有动作预告（008）：红框 = 会替换哪一列，蓝框 = 已在屏幕上 / 进哪个 Shelf。主人 10-21：「托盘点击我没看出来是啥用」——靠预告说清楚。
- **Alt+← / 「返回上一个」**：撤回上一次替换。
- 外观（#36）：常驻（缺省）= 对话区底部、横跨整个对话区（侧栏和 Shelf 全高）的一张不透明圆角矮卡片；自动隐藏 = 悬浮滑出。智能体圆形头像在左组（点了切换工作区），服务 / 成果 / 页圆角方形在右组（点了进当前 Shelf），中间细分隔线；右边「需要你 N」；悬停提示直接说结果。

## 待定：分组方式

| 方案 | 样子 | 优点 | 缺点 |
|---|---|---|---|
| A 不分组 | 左组智能体、右组应用，状态只看标记 | 简单，位置固定好记 | 数量多时分不清哪些在后台开着 |
| B 按状态分段 | 在屏幕上 / 打开着 / 钉住 三段 | 一眼看出后台开着的（主人「当前屏幕 / 所有屏幕」） | 换一次工作区，图标会在段之间跳 |
| C 按工作区 | 屏幕上每个工作区一组（对话 + 它 Shelf 里的），其余「其他」 | 看出谁和谁一起 | 整条托盘跟着工作区重排，难记位置 |
| D 按项目 | 按项目分组 | 多项目时清楚 | 单项目时没用 |

建议：缺省 A；B、D 做成设置项。

## 还要定

- 重启 app 后「打开着」是否保留（建议保留，像浏览器恢复标签）。
- 和 002「最小化」的关系：最小化 = 进托盘成为打开项（见 002）。

## 实现时定下的细节

（10-22，分支 feat/0.2-tray）

- **托盘里有什么**：左组智能体 = 钉住的（钉住顺序）→ 在屏幕上但没钉住的（左→右）→ 打开着、不在屏幕上的（最近的在前；侧栏不认识的不显示）。右组应用 = 只放钉住的服务 / 成果 / 页面 / 链接：**放进 Shelf 的应用不会自动出现在托盘里**（要的话钉住）。打开着的不限个数，托盘放不下时横向滚动（没做「⋯」溢出菜单）。
- **记录方式**：替换不是由每个入口报告的，而是比较前后两次布局（同一列换了智能体 = 一次替换），所以侧栏、托盘、⌘K、拖放、服务接口打开的替换都算。换主机范围不算。打开着的列表存本机（localStorage `cutex-desktop.trayOpen`，最多 40 个），重启后还在；智能体被删掉就从托盘消失。
- **标记**：在屏幕上 = 亮条；收成窄条 = 空心亮条；打开着 = 小点；只钉住 = 无。运行中 = 头像外一圈转圈；需要你 = 数字角标。
- **关闭**：没钉住的项悬停出现 ×：打开着的 = 离开托盘；在屏幕上的 = 关掉那一列（智能体照样运行，然后也离开托盘）。右键：钉到托盘 / 取消固定、关闭、（钉住的）打开方式。
- **点击**：智能体 = 替换聚焦的那一列（已在屏幕上 = 聚焦；收成窄条 = 展开；最小化过的、屏幕上只剩一个工作区 = 回到原来那一边）；Ctrl/⌘+点 = 并排（已有两个工作区 = 换掉另一个）。应用 = 放进聚焦工作区的 Shelf。悬停提示和红 / 蓝 / 绿框说的就是这次点击（同一个函数算出来）。
- **「需要你 N」**：托盘里智能体的需要你之和，0 时不显示；点它 = 打开第一个需要你的。**「返回上一个」**（↶）只在有可撤回的步骤时出现，等于 Alt+←；能撤回：替换、最小化、收成窄条（最多记 30 步，不存盘）。时间线跳转后的「回到」显示时 Alt+← 先给它。
- **分组**：设置 → 托盘 / 托盘右键菜单「分组」：不分组（缺省）/ 按状态 / 按项目。
- **外观（#36）**：托盘常驻 + 停在底部时，是对话区底部一张不透明圆角矮卡片，只横跨会话（两个工作区时横跨两列）；侧栏和 Shelf 全高。两个对话之间夹着 Shelf（并排时 Shelf「永远偏右」）时退回原来的整条带子。〔038（10-23）起：这时卡片横跨两个会话和它们的 Shelf，不再是横跨侧栏的整条带子；图标放不下收进「… N」，不再退回带子。〕桌面露出时卡片在桌面底部。停在上 / 左 / 右、关掉常驻（悬浮滑出）照旧，悬浮时也用同样的卡片样子。
- **工具窗格小片（#7）**：托盘里不再有小片。
