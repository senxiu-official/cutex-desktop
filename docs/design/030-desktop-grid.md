## v2 方案

### 1. 总规则：网格一直在，上面的东西不必是方块

- **每一块都有一个外框**（矩形：x / y / 宽 / 高）——**外框**对齐网格和参考线、参与「不许重叠」的判断、按贴边存位置。
- **看得见的样子**是这一块自己的形状，可以不是矩形：
  - **卡片**（今天的样子，圆角矩形）；
  - **圆形**（例：圆形表盘的时钟）；
  - **路径**（任意多边形 / 曲线外形，例：撕边便签、贴纸、异形小组件）；
  - **抠图**（透明背景的图片，例：立绘）；
  - 以后还可以有：只有文字的块（大字标题、签名）、没有底板的图标。
- **点击跟着看得见的形状走**：圆形、路径用 CSS `border-radius` / `clip-path`，浏览器自己按形状判断点没点中（形状外面的点击落到后面）；抠图按
  **像素的不透明度**判断（读图片的 alpha，低于约 10 % 算透明，点击落到后面的东西上）。原型里三种都有，点立绘透明的地方能点开它身后的磁贴。
- 选中一个非矩形的块时，它的**外框**用虚线画出来（对齐的是外框），右下角是改大小的把手。

### 2. 看不见的网格：8 px 步长

- 步长 **8 px**：和界面本来的间距体系一致（卡片间距 8 / 12、圆角 8 / 12 / 16 都是 4 的倍数，8 的倍数最常见），细到摆放感觉是「自由」的，
  粗到随手一放就是整齐的。12 px 会和 8 px 的界面间距打架（对不上卡片边）；16 px 太粗，小块（时钟、便签）挪一下跳太多；4 px 太细，等于没有网格。
- **平时完全看不到网格**；整理时可以显示**很淡的点阵**（每 2 步 = 16 px 一个点，透明度约 15 %），设置里可以关掉（原型右上「点阵：淡 / 不显示」）。
- 键盘每按一下方向键走 1 步（8 px），Shift 走 10 步（80 px）。

### 3. 智能参考线（像 Figma / Keynote）

- 拖动时，外框的**左 / 中 / 右**（**上 / 中 / 下**）离下面这些线 6 px 以内就**吸过去**，并画一条细的粉色参考线：
  - 别的块外框的边和中线；
  - 别的块边外 **12 px**（标准间距，参考线上标「12」）——两块并排时间距自动一致；
  - 桌面的左右边距和水平中线。
- 没有参考线可吸时，**落到 8 px 步长**上。
- **按住 Alt：都不吸**（不吸参考线、不落步长，1 px 精度），松开 Alt 恢复。
- 改大小时右 / 下边同样吸到别的块的边、边外 12 px 和桌面右边。

### 4. 大小：自由，有上下限

- 大小是步长的倍数（吸到参考线时可以不是），在每种块自己的最小 / 最大之间：

  | 块 | 最小 | 最大 | 形状 | 备注 |
  |---|---|---|---|---|
  | 名片 | 240×72 | 560×160 | 卡片 | |
  | 时钟 | 120×72 | 480×260 | 圆形（缺省）/ 卡片 | 圆形保持 1:1；右键切换 |
  | 需要你 | 240×200 | 480×760 | 卡片 | 内容多了在块里滚动 |
  | 用量 | 240×120 | 640×360 | 卡片 | |
  | 磁贴 | 92×92 | 480×360 | 卡片 | 保留 S 92×92 · M 196×92 · W 404×196 · L 404×300 作为**快捷大小**（右键） |
  | 便签（新） | 120×96 | 400×400 | 路径 | 装饰；文字自己写 |
  | 图片 / 立绘（新） | 64×64 | 1400×1400 | 抠图 | 装饰；**默认保持图片比例，按住 Shift 自由** |

- 内容跟着大小排（时钟的字号跟着变，需要你显示能放下的条数）。

### 5. 重叠：装饰可以叠，功能块不叠

- **功能块**（名片、时钟、需要你、用量、磁贴）的外框**永远不重叠**；拖到别的功能块上按 v1 的规则（**主人 Q2 同意**）：被盖住的**一样大就互换**，
  **不一样大就各自挪到离它最近的空地**（在别的块旁边一个标准间距处找，找不到就放到最下面）；实时预告：蓝虚框「放在这里 · 2 块让开」，被挪的块
  滑到新位置、灰虚框「X 移到这里」。从不拒绝。
- **装饰**（图片 / 立绘、便签、以后的贴纸、文字）**可以叠在任何东西上**，也不会让别人让开。
- **层级**：功能块都在同一层；装饰可以在它们**后面**或**前面**：右键 →「置于顶层（在小组件前面）」/「置于底层（在小组件后面）」。立绘缺省在后面，
  便签缺省在前面。在前面的立绘透明的地方照样点得到身后的块（第 1 条）。
- **锁定**：右键 →「锁定」：锁定的块拖不动、改不了大小（长按也不会拿起来，点击照常），右上角一个小锁；「解锁」恢复。主要给当背景用的大立绘。

### 6. 图片 / 立绘

- 右键桌面 →「添加图片 / 立绘…」：选一张图片（**PNG / WebP 带透明**，也收 JPEG 但那就是矩形）；放在左上起第一处空地，缺省在小组件后面。
- 存在**主页主机**上，和封面一样跟着主人走、每台设备看到的一样。**现在的封面接口只有一个位置**（`PUT /v2/users/me/home/cover`，PNG / JPEG / WebP，
  ≤ 2 MiB；启动页立绘是另一套，只存本机），放不下多张图。需要 cutex 加一组主页图片接口（Management v2）：
  `PUT /v2/users/me/home/images/{id}`（`{contentType, data}`，≤ 2 MiB，每人最多 8 张）、`GET`（带 etag，和封面一样经 main 读成 data URL，
  渲染进程不联网）、`DELETE`；主页文档里只存图片 id、原始宽高。cutex 没有这组接口时：「添加图片」灰掉并说明要升级主机。
- 透明判断用的 alpha 在 main 读图时一并算好（缩小到最长边 256 的一张遮罩），渲染进程按比例查，不用每次解码原图。

### 7. 进入整理、键盘、撤销（v1 照旧，主人 Q4 同意，Q6 去掉抖动）

- **长按任意一块约 400 ms** 拿起来直接拖（400 ms 内移动超过 8 px = 平常的点击 / 滚动）；**右键桌面 →「整理桌面」**；**编辑主页里的「整理」**。
  整理时顶上一条「撤销 · 恢复默认布局 · 完成」，**不抖动**。
- 键盘：Tab 到一块，Enter 进入整理；**方向键 8 px，Shift+方向键 80 px**；**Ctrl/⌘+方向键改大小**（Shift 一次 80 px；圆形、立绘保持比例）；
  Ctrl/⌘+Z 撤销；Esc 完成。
- 撤销：这次整理里每一步（放下、改大小、键盘移动、层级、删除）进撤销栈；「恢复默认布局」= 这一档回到默认样子，本身可撤销。
- 新固定的磁贴放到左上起第一处空地；取消固定 / 删除留下空地，别的不动。
- 减少动态效果：块直接到位、没有滑动；参考线和预告框照常。

### 8. 不同宽度：按贴边存位置（三档，主人 Q3 同意）

- 三档按桌面宽度：**窄 < 760 px · 中 760–1279 · 宽 ≥ 1280**（窗口减去侧栏、Shelf、边距之后的桌面宽度）。每一档只在主人在那一档整理过之后才存
  自己的摆放；没整理过的那一档从最近的已存那一档**推导**。
- **每一块存位置时记它贴着哪边**：离左边近 = 贴左（记到左边的距离），离右边近 = 贴右（记到右边的距离），基本在正中 = 居中（记中线的比例）。
  宽度变了（推导，或同一档里窗口变宽变窄）就按这个重新算 x；y 不变。
- 推导后：
  - **功能块**比桌面还宽的收窄到放得下（不低于最小）；然后按「贴右的先放（右边那一列小组件留在右边），其余按阅读顺序」放，和已经放好的重叠了
    就挪到最近的空地。
  - **立绘不缩放**（它是画，缩小就变味）——除非比桌面还宽或比窗口高 1.2 倍以上，那时按比例缩小到放得下；贴右的立绘缩小时右边不动。
  - **在前面的装饰**（便签、在前面的立绘）推导后盖住了功能块：挪到最近的不盖住任何功能块的地方；**在后面的**装饰盖住了没关系（它本来就在后面）。
    主人自己在这一档把装饰放到功能块上面，就照主人的。
- 原型：在「宽」挪一块，再切到「中」「窄」，上面会写「从『宽』按贴边推导」；时钟、需要你、用量贴右，留在右边；便签挪开了时钟。

### 9. 存储

主页文档（主页主机，`PUT /v2/users/me/home`，带 revision，409 时重读、把**这一档**的这次改动重放上去）加一个字段，旧字段都不动：

```ts
interface HomeDoc {
  // …现有的 layout / blocks / pins / bio / sidebarEntry / showWhenEmpty / homeHost
  desk?: {
    v: 2;
    step: 8;
    /** Per width band, only once the owner arranged there. Positions in px of that band's desktop width. */
    bands: Partial<Record<"n" | "m" | "w", { width: number; at: Record<string, { x: number; y: number; w: number; h: number; ax: "l" | "r" | "c" }> }>>;
    /** Shared by all bands. */
    z?: Record<string, number>;      // decorations only (widgets are one layer)
    lock?: string[];
    shape?: Record<string, string>;  // a widget's chosen shape, e.g. clock "round"
    /** Decorations (no pin): images (the cutex image id, natural size) and notes (their text). */
    items?: Array<{ id: string; kind: "image"; image: string; natural: [number, number] } | { id: string; kind: "note"; text: string }>;
  };
}
```

- 键：区块用它的 id（`profile` / `clock` / `needs` / `stats`），磁贴用 `pinId(pin)`，装饰用 `items[].id`。三档 × 70 块 × 约 60 字节 ≈ 13 KB，
  低于 64 KiB 上限（便签文字限 200 字）。
- 区块开关照旧在 `blocks[].visible`；磁贴的 `size` 照旧写成最接近的快捷大小，所以还没升级的桌面照旧能显示（按旧顺序，看不到装饰）。
- 写：完成整理时、或整理中每一步后去抖 800 ms 写一次。
- **要核对**：cutex `user-home` 是否原样保存不认识的顶层字段（桌面这边 `readHomeDoc` 保留不认识的键）。不保存的话需要在 cutex 的主页文档里加
  `desk`（和图片接口一起，第 6 条）。

### 10. 迁移（从区块顺序）

**不写盘**：没有 `desk` 时，按今天的样子算出默认摆放（主人第一次整理时才存那一档）：名片左上；时钟贴右（缺省圆形 152×152；窄时 120×120）；
需要你、用量在右边一列（窄时放到磁贴下面）；磁贴按今天的顺序和各自的快捷大小，从左上开始、隔 12 px 一个个放；隐藏的区块不放。v1 的 `grid`
字段从来没写过（v1 没实现），不用迁移。

## 边界

- 拖到窗口外松手：回到原位，不存。拖动中窗口宽度变了：按新宽度重算预告。
- 整理时别的设备改了主页：完成时按 409 处理；整理中不打断。
- 桌面比窗口高：照常纵向滚动；拖到靠近上下边缘时自动滚。
- 托盘在桌面上时（`tray: desktop`）：底部留出托盘的高度。
- 立绘被锁定且盖满了桌面：右键空白处（立绘透明处也算）照常有菜单；立绘本身的右键菜单有「解锁」。
- 两个装饰叠在一起：在前面的那个透明处点穿后，落到下一个装饰时同样按它的形状判断。

## 实现时定下的细节（10-22）

- 磁贴从 92 px 改成 96 px（12 步），快捷大小 S 96 × 96 · M 200 × 96 · W 408 × 200 · L 408 × 304。
- 「空地」= 和别的功能块至少隔 12 px；挨着别的块放（参考线、空位）正好隔 12 px，不按 8 px 取整（间距保持一样）。手动放得更近但不重叠可以。
- 宽度分档按**桌面内容的宽度**（窗口减去侧栏、Shelf、边距之后），不是窗口宽度。
