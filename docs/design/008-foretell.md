# 008 动作预告：悬停时先描出会发生什么

状态：**已实现**（10-22，分支 feat/0.2-tray，待合并；已定 10-21 主人：「这个红框显示替换太好用了！非常直观……别的地方如果有也可以用上」）。预览：`.claude/preview-tray-taskbar.html` v3。

## 规则

凡是一次点击会**改变布局**（替换、并排、进 Shelf、收起、关闭、最大化），悬停（或键盘聚焦）在入口上时：
1. 用虚线描出**将被影响的那块**；
2. 在那块上贴一句**结果**（不是动作名）：「点击会替换 X（它会留在托盘里）」「在 X 的 Shelf 打开 Y」；
3. 按住修饰键时预告跟着变（Ctrl/⌘ = 并排 → 改成绿色、描出将出现的位置）；
4. 移开就消失，不改任何东西。

颜色固定：**红 = 替换 / 关掉**（会有东西离开屏幕）· **蓝 = 聚焦 / 在这里打开** · **绿 = 并排（新增一列）** · **灰 = 收起 / 收进托盘**（还能回来）。

## 用在哪（实现时逐个加）

- 侧栏智能体行、托盘图标、⌘K 的结果行（选中即预告）；
- 会话标题的 收起 / — / ⤢ / 关闭；Shelf 的收起、关闭；
- 拖放：拖动中目标区域已有高亮，统一成同一套颜色和文字；
- 「太窄？收起 X」这类建议按钮；
- 最大化 / 独占：描出会被挤到两边或收成窄条的面板。

## 边界

- 悬停 150 ms 后才显示，划过不闪；减少动态时没有淡入。
- 触屏没有悬停：长按显示预告，松开不执行。〔不做：没有触屏设备在用（10-22），见下。〕
- 预告和真实结果必须同一段代码算出来（不能「预告说替换左边、实际替换右边」）：实现时预告调用同一个「这次点击会做什么」的函数。

## 实现时定下的细节

（10-22，分支 feat/0.2-tray）

- **给其他成员用**：`lib/foretell.ts`（`useForetell(compute)` 返回要挂在按钮上的 onPointerEnter / Leave / Down、onFocus / onBlur；`foretellAfterDelay` 给 ⌘K 这种「选中即预告」用）+ `components/ForetellLayer.tsx`（App 里已挂）。一个预告 = 颜色（replace 红 / open 蓝 / beside 绿 / fold 灰）+ 一句结果 + 要描的区域（CSS 选择器或固定方框）。
- **同一个函数**：按钮先算出一个 effect `{ foretell, run }`（布局类的在 `lib/workspaceEffects.ts`：agentEffect、refEffect、stripEffect、minimizeEffect、closeEffect、makeRoomEffect…），悬停显示 `effect.foretell`，点击执行 `effect.run()`。
- **时机**：悬停 150 ms 后出现；移开、按下、失去焦点就消失；只有键盘聚焦（:focus-visible）才预告，鼠标点击带来的聚焦不预告。按住 / 松开 Ctrl/⌘ 立即重算。减少动态时没有淡入。框跟着列滑动逐帧更新。
- **已接上**：侧栏智能体行（含窄栏、离线行、「在旁边打开」）、托盘每一项、⌘K 选中的行（智能体 / 走工作区的服务、成果、页面；其他打开方式的行不预告）、对话标题的 ‹/› · — · 放大 · 关闭、「太窄？收起 X」。
- **菜单项**（10-22，feat/0.2-tray2）：会改布局的菜单行也预告——悬停或用方向键移到那一行，150 ms 后在受影响的地方描框并说结果，换行 / 关菜单就消失。菜单行带一个 `foretell()`（`lib/contextMenu` MenuAction），和这一行的 onSelect 用同样的输入算（`lib/menuForetells.ts`）。已接上：对话标题 ⋯ 的全屏 / 独占 / 移到左边·右边；{{shelf}} ⋯ 的收起 / 展开 / 最大化 / 独占 / 全屏 / 移到另一边 / 关闭；工具窗格「—」的移到另一页（每一页、新的一页）/ 关闭；托盘右键的关闭（打开着的 = 灰框「X 离开托盘」，在屏幕上的 = 红框关掉那一列）。对话标题 ⋯ 里现在没有「最大化 / 关闭」这两行（它们是标题上的按钮，按钮本身已有预告）；窄标题折进 ⋯ 的那几项（服务 / 通知 / 项目）不改布局，不预告。
- **拖放**（10-22）：工作区拖放的目标高亮统一成这四种颜色和说法——拖到 {{shelf}} = 蓝「放进 X 的 {{shelf}}」（投影的副标题照旧说明是实时的 X）；拖到窗口边缘 = 绿「并排打开」；拖到对话上 = 红「替换 X（它会留在托盘里）」，拖到空着的工作区（桌面）= 蓝「打开在这里」；不能放 = 灰，说原因。图例、边缘的竖条、跟着指针的小标签用同样的颜色。{{shelf}} 里拖窗格 / 标签（SideDndLayer）本来就是蓝色「放在这里」，没动（琥珀色是「允许混排」关时「标签行不收别的种类，会放成下面一个窗格」的提醒，保留）。
- **触屏长按**：不做（10-22 主人：没有触屏设备在用）。
