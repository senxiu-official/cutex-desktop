# Layout action previews

Hover or keyboard focus can preview the area affected by a layout action. The preview explains the result, such as replacing a conversation, opening inside a Shelf or adding a column. Modifier keys update the preview. Red denotes replacement or removal, blue focus or opening, green an added column and grey collapse. Previewing does not change the layout.
