# Open content in its originating Shelf

Actions inside a conversation or Shelf open related content in that workspace according to the page-opening setting. The originating pane remains the placement context even when another conversation has focus. Source actions and agent reveal requests use the same placement rules. A collapsed Shelf can reopen when an explicit open action targets it.

See [Architecture](../DESIGN.md) and [Module contracts](../desktop-modules.md) for related interfaces.
