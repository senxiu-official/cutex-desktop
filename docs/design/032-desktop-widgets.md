## 1. 模型：种类、实例、外框、来源

- **小组件种类**（`desktop.widget` 插槽里的一条）：某个模块声明的一种小组件——名字、图标、大小范围、形状、能不能放多个、缺省放哪、设置表、
  刷新节奏、来源、画它的组件。
- **实例**：桌面上实际的一块。两种来法：
  - **主人加的**（`instances: "owner"`，缺省）：存在主页文档 `HomeDoc.desk.items`（`{ id, kind, settings }`）。一种只能放一个的，实例 id = 种类 id；
    能放多个的（`multiple`）第二个起是 `种类#2`。
  - **模块列出的**（`instances: "module"`）：模块自己知道有几个（例：每个固定的磁贴一个，来自共享的固定列表），用 `useInstances()` 报给桌面，
    删除时调它的 `remove(id)`（例：取消固定）。
- **外框**：实例在桌面上的位置和大小（px），对齐看不见的 8 px 网格和参考线，**功能块之间不重叠**（030 v2）。每个宽度档存一份
  （`HomeDoc.desk.bands`，带贴边），没整理过的档从最近一档推导。
- **形状**：外框里看得见的样子——卡片（今天的玻璃卡片）、圆、路径（`clip-path`）、无底板（组件自己画，例：今天的时钟）。点击跟着看得见的形状走
  （浏览器按 `border-radius` / `clip-path` 判断）。抠图形状（按像素透明度点穿）留在 030 v2，第一版没有图片小组件，所以没做。
- **来源**：内容从哪里来——模块 / 服务 / 智能体（第 3 节）。

## 2. 组件拿到什么（`DesktopWidgetProps`）

| 字段 | 是什么 |
|---|---|
| `instanceId` | 这一块的 id |
| `width` / `height`、`steps` | 外框的 px，和网格步长（8 px 一步）；组件按它排版（字号、显示几行） |
| `theme` | 现在的配色：`light` / `dark` |
| `settings` / `setSettings` | 这一块的设置（种类的缺省 + 主人改过的，已经按设置表检查过）；`setSettings` 存回主页文档 |
| `reducedMotion` | 系统要求减少动态效果：不做动画 |
| `arranging` | 正在整理：外壳拿走指针，组件里的按钮这时不该动作 |
| `now` | 共用计时器的时间（`refresh: "minute"` 的每到整分变一次） |
| `hostId` | 主页文档所在的主机 |
| `source` | 这一块的来源 |
| `actions` | 外壳的动作（第 3.4 节） |

- **数据只能经自己模块的窄服务**拿（`ctx.services`、模块自己的钩子）；**不能**直接调 daemon 的接口。
- **刷新**：要按时间变的（时钟）声明 `refresh: "minute"` 或 `"second"`，用外壳**共用的计时器**——每种节奏一个定时器，不管桌面上有几个时钟；
  不准自己 `setInterval`（性能预算，第 9 节）。
- **设置表**（外壳画表单，不用自己写设置界面）：`text`、`number`、`toggle`、`select`、`timezone`、`list`（一组平的字段，最少 / 最多几行）。
  存的值按表检查，不合格的用缺省；缺省可以是随界面语言变的函数（例：城市名）。

## 3. 来源（以后接智能体、服务，契约现在就定好）

### 3.1 模块（已实现）

内置模块或可下载的第一方模块包（§23）里的 React 组件。今天的五个和世界时钟都是这种。

### 3.2 服务（一部分已实现）

- cutex 已经有服务磁贴（能力 `service-tiles`：服务发布一个磁贴模板和数据，桌面画出来）。**固定的服务就是 `home.tile` 小组件的一个实例，来源 =
  这个服务**（`{ kind: "service", hostId, slug }`）——已经接上：右键能看到「来自：服务 X」。
- 以后：一个服务**声明更多的小组件**（例：天气服务给一个三天预报的组件）。做法：cutex 的服务描述里加 `widgets: [{ id, title, sizes, template }]`，
  桌面的一个模块（`services`）把它们报成 `instances: "module"` 的种类实例，画法和今天的服务磁贴一样（模板 + 数据，桌面画，不跑服务的代码）。
  这需要 cutex 扩服务描述（Management v2），桌面这边契约不用改。
- 服务停了 / 主机离线：实例**留在原处**，画成「已停止」/「主机离线」（今天的服务磁贴已经这样），点它给出原因；服务被删了：显示「服务已不在」，
  主人可以删掉这一块。不自动删（数据是主人的摆放）。

### 3.3 智能体（只写了规格，没做）

- 智能体发布一个 **HTML 成果**，主人把它放到桌面上 = 一个实例，来源 `{ kind: "agent", hostId, sessionId, artifactId }`。
- 画法：和成果页面一样的**不透明 frame**（`@cutex-desktop/opaque-frame`，§10.2）：opaque origin、没有网络、没有预加载 / Node / 令牌，main 一次性
  提供文档。**只开设计 004 的三个口**：自己的小存储（每个成果 5 MB）、**主人确认后**交回做它的智能体、点击时复制。没有别的口。
- 可选的**只读数据**：智能体另外发布一个很小的 JSON 成果（例：≤ 64 KB），小组件按 id 订阅；智能体重发布 = 数据更新（frame 收到新数据，不收任何别的）。
- 智能体归档 / 删除：实例留着，画成「来自已归档的智能体」，内容停在最后一版（frame 照旧只读）；交回的口关掉。主人可以删掉这一块。

### 3.4 动作（`actions`）

小组件自己**不能**做任何会影响别处的事；要打开或发送，只能调外壳给的四个动作，它们就是侧栏、托盘、⌘K 用的同一套（动作预告、确认都照常）：

- `openAgent(hostId, sessionId)`：打开那个智能体的会话（和点侧栏一样）。
- `openPage(page, params)`：打开一个页面（例：项目概览）。
- `openService(hostId, slug)`：打开服务（和点固定的服务磁贴一样）。
- `sendToAgent(hostId, sessionId, text)`：发给智能体——**一定先弹主人确认**（显示要发的文字和发给谁）。v1.22 里它**总是返回 false**（保留），
  和智能体来源的小组件一起做（走 main 的确认框，同设计 004 的「交回」）。

### 3.5 权限与出处

- 每一块都能看出**谁提供的**：右键菜单第一行「来自：…（内置）/ 服务 X / 智能体 Y」，设置面板的标题下面也写。
- 第三方 / 智能体来源的小组件**永远**在不透明 frame 里（第 8 节），拿不到别的数据；模块小组件和其他模块一样受模块的能力门控（`requires`）。
- 主人随时可以删掉任何一块；模块关掉时它的小组件不显示，摆放留着，再打开就回来。

## 4. 生命周期

- **添加**：右键桌面 →「添加小组件 ▸」（列出主人可以加的种类：只能放一个的还没放、能放多个的总是在）；编辑主页面板里每种一个开关，能放多个的
  有「再加一个」。新的一块放在左上起第一个空地。
- **复制**：能放多个的右键 →「复制一个」（带一样的设置）。
- **删除**：右键 →「从桌面移除」（主人的）/「取消固定」（磁贴）；整理时选中按 Delete。留下空地，别的不动。
- **设置**：右键 →「小组件设置…」或编辑主页面板里的设置按钮：面板换成这一块的设置表，「返回编辑主页」回去。
- **恢复默认布局**：这一档回到缺省位置（实例和设置不变），可以撤销。

## 5. 存储（`HomeDoc.desk`）

```ts
desk: {
  v: 1,
  items: [{ id: "world-clock.clock", kind: "world-clock.clock", settings: { cities: [...], hour12: false, showDiff: true } }, …],
  off?: ["home.tile"],                     // 模块实例整体关掉的种类
  bands: { n?|m?|w?: { width: 1272, at: { "home.profile": { x: 0, y: 0, w: 352, h: 96, ax: "l" }, … } } },
}
```

- 主页文档在主页主机上（`PUT /v2/users/me/home`，带 revision，冲突时重读、把这次改动重做一次）。**cutex 原样保存不认识的顶层键**
  （`user_home.rs`：「client-owned and forward compatible」，有测试），所以不用改 cutex。
- 迁移：没有 `desk` 时按旧的 `blocks`（哪些显示）算出缺省，**不写盘**；主人第一次改才写。写的时候同步旧字段：`blocks[].visible` 跟着实例有没有，
  `pins[].size` 跟着磁贴的大小（最接近的 S / M / W / L），还没升级的桌面照旧能显示。
- 大小：三档 × 70 块 × 约 60 字节 + 设置，远低于 64 KiB。

## 9. 第三方 / 外部小组件

- 走已有的不透明插件沙箱（`plugin-sandbox` / `opaque-frame`，§10）：一个外部插件声明小组件 = 外壳给它一个 frame 的外框，frame 里是插件自己的
  文档；**和插件页面同样的限制**（不透明源、没有网络、没有令牌和 IPC、main 一次性提供文档）。它收到的只有：大小、配色、减少动态效果、整理中、
  它的设置（JSON）；它能发的只有：「保存设置」（按它声明的设置表检查）。不接 `actions`（以后要接，也只走主人确认）。
- 这一版没实现（`plugins` 模块默认关）。

## 10. 版本与兼容

## 11. 性能

- 计时器共用（第 2 节）；不在屏幕上的桌面（被窗格盖住）不画内容，计时器跟着没人订阅就停。
- 小组件出错只坏它自己那一块（`ItemBoundary`）。
- 整理时外壳拖动只改外框的位置，不让组件每帧重排（组件只在大小变时重画）。

## 12. 大格子（契约 v1.23，主人 2026-10-24）

主人：「我是觉得可以固定，或者给个 grid，现在 grid 好像太细」；看过预览（`.claude/previews/preview-widgets-v1.html`）后定了「96，可以」。

- **格子**：一格 96 px，两格之间 16 px（一格加间距 112 px）。外框只能是整格：n 格宽 = n × 112 − 16 px。格子在桌面宽度里居中，宽度不够
  一整格的余量分在两边。1300 px 宽的桌面放 11 格。
- **大小**：种类用 `size.cells` 给最小 / 最大 / 缺省 / 快捷大小（格数）。1.22 的种类只写了步长也能用：每个大小换成最近的格数（至少一格；
  最大比最小还小时抬到最小），**不拒绝旧的声明**。磁贴的 S / M / W / L 正好是 1×1 / 2×1 / 4×2 / 4×3。
- **整理**：参考线和 Alt 去掉了（整格本身就对齐）；整理时格子淡淡地显出来；拖到哪一格就放哪一格，放下的规则照旧（一样大互换、否则就近
  避让）；改大小按整格；方向键一格、Shift 四格。
- **缺省布局**：名片在左上；时钟和世界时钟在右上**左右并排**（主人 10-24：「时钟不合成，左右平铺即可」）；需要你、用量在右边一列；磁贴
  在左边主区。
- **存储**：`HomeDoc.desk.cells[band] = { cols, at: { id: { x, y, w, h, ax } } }`（整格）。1.22 的 `bands`（px）**不再写**，原样留着：
  - 读的时候没有 `cells` 就从 `bands` **换算一次**（大小取最近的格数；位置按贴边取最近的格子——左贴边看左边、右贴边看右边、居中看中线；
    重叠的按顺序去最近的空地，近处都没有就放到最下面）。换算的结果不写盘，主人在这一档改了东西才写进 `cells`。
  - `bands` 是备份：还没升级的桌面照旧读它；右键「恢复换大格子前的摆法」去掉这一档的 `cells`，重新从备份换算。旧版本改桌面时会丢掉
    `cells`，这边再从 `bands` 换算，不会坏。
- 实现：`modules/home/deskCells.ts`（纯函数）+ `DeskSurface.tsx`；`modules/widgetTypes.ts`（`WIDGET_CELL` / `WIDGET_GAP`、`cellsOfSteps`、
  `cellSizesOf`）。测试 `test/deskCells.test.ts`、`test/deskSurface.test.ts`。

## 13. 小格子、点阵、浮动的编辑主页（契约 v1.24，主人 2026-10-24）

  两个单位 + 间距 = 96 px = 1.23 的一格。1.23 的摆放（`desk.cells`）读的时候每个数乘 2（`unitsOfCellBand`），屏幕上一个像素都不动；改了才写
  `desk.units`。`cells`、`bands` 都留着当备份；「恢复换大格子前的摆法」去掉这一档的 `units` 和 `cells`，从 1.22 的 `bands` 重新换算。
- 最小 2 × 2 个单位（40 px 一格放不下东西）。内置小组件的大小 = 1.23 的格数乘 2。方向键一个单位、Shift 四个。
- 整理时的格子：方块太密（主人：「太难看了」）→ **点阵**：四个单位相交的地方（间距的十字中心）一个点，**所有点一样大**（主人：不用分大小点——
  格子跟着桌面宽度居中，拖侧栏时会移，「大格」的点不会一直是那几个）。只在整理时画。
- 整理时桌面上的小组件往下让出整理条的高度（44 px），整理条不再盖住最上面一行。
- **编辑主页**（主人：「好占位置」）：不再是右边一整列；浮在桌面上、整理条下面，高度跟内容走，按标题栏能拖走；× 和整理条上的「编辑主页 ▴」
  把它收起（整理照旧），再点「编辑主页 ▾」展开。
- **小组件设置**：右键「小组件设置…」或编辑主页里的设置按钮 → 在那一块**旁边**弹出一个小框（右边放得下放右边，否则左边），写着来自哪里，
  下面是它的设置表；× 关掉。不再把编辑主页面板换成设置。

## 实现时定下的细节

- 无底板形状 `bare`（契约里加的）：今天的时钟没有卡片，主人说保留，所以要有「不画底板」的形状。
- 设置缺省可以是函数（`defaults(locale)`）：城市名随界面语言（中文「堪培拉 / 重庆」，英文 Canberra / Chongqing）。
- 加一块时放在**这一档**左上起第一个空地；别的档推导时它也找第一个空地。
- 编辑主页面板的「显示的区块」改成「小组件」：每种一个开关（能放多个的有「再加一个」、有设置的有设置按钮），上下移去掉（位置靠拖）。
- 同一张卡里功能块之间至少 12 px 间距才算「空地」；手动放得更近（不重叠）可以。
- 显示「已经多久 / 几分钟前」的小组件也要 `refresh: "minute"`，不只是时钟（正在运行 原来没写，时长要等数据变了才动）。
- 「某个智能体正在做什么」不需要 cutex 新接口：侧栏第二行用的活动行（cutex 会话资源里的 `activity.lastToolCall` / `lastOutput`，当前主机再由事件实时更新）对**没打开的对话**也有。给小组件的读法是 `agentActivityOf(s, focus, row)` + `runningStepOf(…)`（`lib/activity.ts`）；对话打开着时再用时间线给的更细的词（推理中、等待批准……）。别的主机的活动行随它的侧栏快照刷新，会慢一点；以后若要更实时，再请 cutex 推送（不急）。
- 列表设置读的时候，存着的每一行缺的字段先用 `itemDefaults` 补上再校验：以后给列表加字段（世界时钟加了图标），主人已经存的城市不会被当成无效而换回缺省。已经有、但值不对的字段仍然让整张列表无效。
- 桌面上不带卡片的文字（两个时钟，`.home-clock`）的阴影按主题分：浅色桌面（天空偏白，时钟正好在亮处）多一圈很淡的深色描边和贴身阴影，深色不变。没有按壁纸实际亮度去测——要的话以后再做。
- 日期文字统一用 `lib/dateText` 的 `formatDate`：有的 ICU 会写成「10 月 22 日」，这里去掉数字两边的空格（只管中文、日文），中文在星期前留一个空格。
- 小组件模块的繁体中文放在模块自己的 `i18n.ts` 里，由 `scripts/zh-hant.py --write` 生成，不再手改共用的 `i18n/zh-Hant-CN.ts`（世界时钟、正在运行已经搬过去）。
- 小组件打开东西一律走 `actions`。主页模块自带的两个例外：名片打开主页模块自己的个人页窗格，磁贴打开它的钉选（可能是成果、链接、页面钉选）——这两样 `actions` 做不了。需要你 已改为走 `actions`。

- **亚克力 + 少框（主人 2026-10-24，预览 `.claude/previews/preview-widgets-v1.html`）**：外壳的卡片（`.home-glass`）换成亚克力——更重的模糊（32 px、饱和 1.5）、一层底色、很淡的颗粒（内嵌 SVG 噪点，CSP 允许 `data:`）、顶边一道亮线。只有列表（需要你、正在运行）和内容多的模板磁贴（W / L）留卡片；名片、用量、S / M 磁贴改成 `bare`，白字带阴影直接写在壁纸上（`.home-bare`），能点的悬停时浮出一层淡亚克力（`.home-bare-hit`）。智能体磁贴不画框：头像 `Avatar cutout` 整张画出（不裁圆、无描边、无项目角标），立绘本来就是透明底；没有图片的（emoji / 字母）仍是圆的，缩到一半大。契约没变（只是内置种类换了 `shape`）。
