# Visual language

Application surfaces use neutral colors and shared typography, spacing and corner-radius tokens. Avatars identify agents and Profiles. Portrait, emoji and initials styles can be selected; changing the style does not silently replace existing pinned avatars. The sidebar provides roster and avatar-strip presentations. Appearance settings describe their device, host or Profile scope.

See [Architecture](../DESIGN.md) and [Module contracts](../desktop-modules.md) for related interfaces.
