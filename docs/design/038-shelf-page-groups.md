# 038 Shelf 页组：胶囊、合并 / 拆开、页面单独开、新建{{agent}}、设置打开时的托盘

状态：**已实现**（分支 `feat/0.2-shelf-groups`，未合并）。主人 2026-10-23 看过预览后同意：
`.claude/previews/preview-shelf-page-groups.html`（每一项都有「现在 / 改后」）。

术语（预览 §1）：Shelf → **页**（主人说的「组」就是页，Rail 上一页一个按钮，最多 9 页）→ **窗格**（一页里上下最多 3 个）→ **标签**。

## 1. Rail 上一页一个胶囊

**问题**：Rail 上每页只有一个图标（页的图标或第一个窗格的图标），看不出「文件 + 预览」是同一页。

**规则**（`components/side/ShelfRail.tsx`，内容来自 `lib/sidePills.ts` `pillContent`，第 3 步删掉的胶囊找回来）：

- 只有一个窗格的页 = 和现在一样的普通按钮（页图标、主人选的图标照旧）。
- **两个以上窗格的页 = 胶囊**：一个竖着的圆角框，里面按窗格的上下顺序叠着每个窗格的种类图标（最多 3 个，一页最多 3 个窗格）。
  **没有把手标记**：框和图标之间的空隙 = 整页，图标 = 那个窗格。
- 悬停：在框 / 空隙上 = 整个框描一圈淡的强调色；在图标上 = 只亮那个图标。光标是「抓手」。
- 提示：「页名 · Alt+n」，胶囊再加一行「拖边框 = 移动整页 · 拖图标 = 移动这个窗格 · 右键 = 菜单」。
- **点**：别的页（框或图标）= 换到那一页（点的是图标就再聚焦那个窗格并闪一下）；正在显示的页的图标 = 聚焦那个窗格并闪一下；
  正在显示的页的框 = 什么都不做（009 的规则不变）。
- 需要你的数目、忙的点、新东西的点照旧按页画在胶囊上（按图标分不做：页级已经够看）。
- 收起成 Rail 的 Shelf、另一个工作区的 Rail、Rail 常驻时关着的工具区画同一种胶囊。
- **右键**（框或图标）：原来的页菜单（重命名、换图标、在所有对话中显示、删除）+ **移到上面 / 移到下面**（原「上移 / 下移」改名）
  + **拆开「窗格名」**（右键的是图标就拆那个，否则拆聚焦的那个 / 最下面那个；只有一个窗格时灰掉；9 页满时灰掉）
  + **合并到上一页**（上一页加上这一页超过 3 个窗格时灰掉）。

## 2. 拖动合并 / 拆开

- **拖整页**（单窗格按钮、胶囊的框）：
  - 放在别的页按钮 / 胶囊的**中间**（上下各 25 % 以外）= **合并**：那一页在下面加上这一页的所有窗格，这一页消失，显示合并后的那一页。
    合起来超过 3 个窗格 = 拒绝「一页最多 3 个窗格」。（另一个 Shelf 的页也可以合并进去。）
  - 放在按钮的**上 / 下 25 %** = 调顺序 / 搬到另一个 Shelf（原来的规则，§24.12.4：一条横线「移到这里」）。
  - 放在 Rail 下面的「新页」上 = 移到这条 Rail 的最后（原规则）。
- **拖一个窗格**（胶囊里的图标，或像以前一样拖窗格头）：
  - 放在别的页按钮 / 胶囊上 = 进那一页，成为下面的一个新窗格（同种类的窗格已经在那儿 = 成为它的标签，原规则）；满 3 个拒绝。
  - 放在「新页」上 = 自己成一页（≤ 9 页）。
- 拖动开始后，Rail 底部的 ＋ 变成虚线框「新页」（比平时高一点），说明放在这里会怎样。
- 拖胶囊里的图标不切页（只有停 0.4 s 才切，原规则）。
- 实现：`lib/sideDnd` 探测页按钮时多给一个 `zone`（上 / 中 / 下）；`lib/sideDrop` `pageDropTarget` 中间 = `mergePage`；
  新函数 `lib/sideLayout` `mergePageInto`（≤ 3 才合，否则原样返回）、`splitCardOut`（拆到紧挨着的下一页）。

## 3. 页面默认一个一个开

**问题**：从启动器 / 侧栏打开项目页、委托、服务时，它们被塞进正在显示的那一页，和原来的窗格平分高度（1/2、1/3），主人没有要求合在一起。

**规则**（`lib/sideLayout.ts` `place()`）：种类声明的 `otherwise`（缺省 `"new-page"`）以前被忽略了——没有规则命中时都进「右 Shelf 正在显示的页」。现在：

- `otherwise: "new-page"`（缺省，页面种类 `page:<id>` 都是）：没有显式页、覆盖、`prefer` 命中时
  → 已经有这种窗格的页（任何一页）= 那个窗格加标签、跳过去（「已经开着就跳过去」）；
  → 否则默认 Shelf 的**新页**，整页高；9 页满了才退回原来的规则（正在显示的页）。
- `otherwise: "active-page"`（投影、对话引用等少数种类）不变：进聚焦的页。
- 「允许混排」开着时一样：同种类的窗格加标签；混排只影响「这一页满了」之后的退路（不变）。
- 显式的 `prefer` 规则（例如差异跟着「改动」那一页）不变——那是种类自己声明要在一起。
- **侧栏入口按 Ctrl/⌘**（`lib/openModifiers`）：页面入口 = 「并排」打开（`lib/workspaces` `openRef(…, "beside")`：两个工作区时进另一个
  工作区的 Shelf，一个工作区时进这个 Shelf 的新页）；`run()` 入口照旧。

§24.4 和 §24.12.2 以前互相矛盾（一个说「开在自己的页」，一个说「进正在显示的页」），现在两处都写成上面的规则。

## 4. 新建{{agent}}像「新工作」

**问题**：「新建{{agent}}」是一个页面，按「页面打开位置 = Shelf」开进了 Shelf，成了一个窄窗格，对话列没变。

**规则**：

- 普通点 = **换掉聚焦的对话列**（表单盖在对话列上，和「新工作」一样，不看「页面打开位置」）；原来的对话没关，留在侧栏 / 托盘里。
- **Ctrl/⌘ + 点** = 在旁边开一列空的会话列显示表单（已经两列 = 用另一列）。
- 建好之后新{{agent}}进表单所在的那一列（原来的选中流程）。
- 实现：`store.ts` 的「盖在对话列上的页面」多一个 `NEW_AGENT_PAGE`（和 `DRAFT_CHAT_PAGE` 一样由外壳点名）；`lib/paneLayout` `openEmptyBeside`。

## 5. 设置打开时的托盘

**问题**：设置 Shelf 打开后对话变窄，托盘里的图标放不下，托盘退回横跨整个窗口的底条，侧栏、Shelf、设置 Shelf 都矮一截。

**规则**（`lib/trayRoom.ts`、`components/ChipTray.tsx`）：

- 托盘常驻在底部时，托盘**一直**是对话下面的那张卡片；图标放不下时，放得下的照常显示，其余收进最后的「… N」，点它弹出一个列表
  （图标 + 名字，点了和点托盘里的一样）。不再因为「放不下」退回底条。
- 底条只留两种情况（设计 001 / 002 原来就有的）：
  - 两个对话中间夹着 Shelf（并排时 Shelf「永远偏右」）：卡片会从 Shelf 下面穿过去；
  - 会话窄到连「… N」都放不下（只看 Shelf、只剩 44 px 窄条）。
  这两种时底条**从侧栏右边开始**，侧栏保持整高。
