# Agent roster

The sidebar groups agents by project and separates active work, online idle agents and offline agents. Independent agents and quick chats remain accessible alongside project folders. Name ordering is configurable. System rows can use a dashed divider or grey band; reordering waits until the pointer leaves the roster. Remote hosts display agents progressively, retain previously read entries after an individual read fails, and show the last known list during startup synchronization. Archived agents load on demand. Hosts outside the active view poll less frequently.
